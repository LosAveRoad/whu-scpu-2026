## 二、三大验收任务与评分梯队（加分：任务 3 > 任务 2 > 任务 1）

| 任务等级 | 核心内容 | 使用 `.coe` | 验收现场演示要求 |
| :--- | :--- | :--- | :--- |
| **任务 1（基础）** | 四模块顺序执行 | `coe/test_2026.coe`（12 条指令） | 先用 `SW[14]=1` 循环显示 12 条 ROM 指令；再由老师在 RF、ALU、DM 中抽一个模块，通过 `SW[14:11]` 切换并按手册键位演示功能 |
| **任务 2（进阶）** | 实现一种 **B 指令** 跳转 | `coe/Test_all.coe`（或筛选出对应 B 指令块） | 可从 `Test_all.coe` 筛选与所选 B 指令（如 `beq`/`bne`/`blt`/`bge`/`bltu`/`bgeu`）相关的指令按顺序执行，条件满足时正确跳转到目标地址（支持 `PC` 字节寻址与 `PC+imm` 跳转，其余无关指令可删） |
| **任务 3（最高加分）** | 实现一种 **J 指令** 跳转 | `coe/Test_all.coe`（或筛选出对应 J 指令块） | 可从 `Test_all.coe` 筛选与所选 J 指令（`jal` 或 `jalr`）相关的指令按顺序执行，正确跳转到目标地址并将返回地址 `PC+4` 写入 `rd`（通常 `x1`），其余无关指令可删 |

## 三、`Test_all.coe`（277 条指令）分块索引

文件已存入 `coe/Test_all.coe`。按 32 条指令为一组拆解如下，做任务 2 或任务 3 时可直接定位对应区块：

| 区块 | 指令序号（0-based） | 字节地址 `PC` | 考察指令 | 关键跳转指令示例 |
| :--- | :---: | :---: | :--- | :--- |
| Block 0 | `0 .. 31` | `0x000 .. 0x07C` | **`beq`** | `[14] beq x0,x0,+16`、`[23] beq x9,x8,-88`、`[24] beq x7,x7,-24` |
| Block 1 | `32 .. 63` | `0x080 .. 0x0FC` | **`bne`** | `[46] bne x0,x1,+16`、`[55] bne x0,x0,-88`、`[56] bne x8,x9,-24` |
| Block 2 | `64 .. 95` | `0x100 .. 0x17C` | **`blt`** | `[78] blt x0,x1,+16`、`[87] blt x0,x0,-88`、`[88] blt x8,x9,-24` |
| Block 3 | `96 .. 127` | `0x180 .. 0x1FC` | **`bge`** | `[110] bge x0,x0,+16`、`[119] bge x8,x9,-88`、`[120] bge x7,x7,-24` |
| Block 4 | `128 .. 159` | `0x200 .. 0x27C` | **`bltu`** | `[142] bltu x0,x1,+16`、`[151] bltu x0,x0,-88`、`[152] bltu x8,x9,-24` |
| Block 5 | `160 .. 191` | `0x280 .. 0x2FC` | **`bgeu`** | `[174] bgeu x0,x0,+16`、`[183] bgeu x8,x9,-88`、`[184] bgeu x7,x7,-24` |
| Block 6 | `192 .. 223` | `0x300 .. 0x37C` | **`jal`** | `[206] jal x1,+16`（`0x338 -> 0x348`）、`[215] jal x1,-20`（`0x35C -> 0x348`） |
| Block 7 | `224 .. 252` | `0x380 .. 0x3F0` | **`jalr`** | `[237] jalr x1,960(x0)`、`[246] jalr x1,960(x0)` |
| Block 8 | `253 .. 276` | `0x3F4 .. 0x450` | **`sll`/`srl`/`sra`** | `[257] sll`、`[265] srl`、`[273] sra` |

> **注意**：`Test_all.coe` 中的跳转偏移量均按 **字节地址 `PC`** 计算（每条指令占 4 字节，`PC` 每次 `+4`，取指传给 `dist_mem_im` 时用 `PC[7:2]` 或 `PC[9:2]` 作为字地址）；且如果支持 `jal` / `jalr`，`WDSel` 需用 2 位选择 `PC + 4` 写回 `rd`。

## 四、开关与显示切换参考（NEXYS4）

- `SW[15]`：`1` = 慢速时钟；`0` = 快速时钟
- `SW[14:11]`：`4'b1000` 显示 ROM 指令；`4'b0100` 显示 RF；`4'b0010` 显示 ALU（A, B, C）；`4'b0001` 显示 DM
- `SW[4:3]`（DM 单独演示）：`00` = SW（字）、`01` = SH（半字）、`11` = SB（字节）
- `SW[1]`：`1` = 调试模式（冻结 RF）；`0` = 正常模式
- `SW[0]`：`0` = 显示 CPU/模块数据（`display_data`）；`1` = 显示测试动画/图案（`led_disp_data`）

## 五、本科生实验报告格式规范（武汉大学计算机学院）

1. **封面**：
   - 标题：`武汉大学计算机学院` / `本科生实验报告`（1 号宋体居中）
   - 实验名称：`XXXXXX 实验`（2 号黑体居中，标题行间距 32 磅）
   - 信息栏：专业名称、课程名称、指导教师（含职称）、学生学号、学生姓名、日期（`二〇XX 年 X 月`，宋体小 3 居中左对齐）
2. **正文三段结构**（章节标题黑体 4 号，正文宋体小 4，行间距固定值 23 磅，字符间距标准）：
   - `1 实验内容`（涉及并要求掌握的知识点、必要原理分析）
   - `2 实验步骤与分析`（软硬件环境、具体步骤、过程记录、故障分析与排除方法）
   - `3 实验结果与总结`（实验结果分析、体会、改进意见）
3. **公式、图表**：公式居中右编号如 `(1.1)`；表标题中文黑体 4 号、数字/字母 Times New Roman 粗体小 4，表内容宋体或 Times New Roman 小 5；图标题居中在图下方（如 `图 1.2 数据通道模块内部结构`）。
4. **末页**：保留 `教师评语评分` 页（评语、评分、评阅人、年月日）。
